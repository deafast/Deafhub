# Макет главной страницы: актуальный просмотр

Открывать preview.html. Изображение home-restored-card-background.png содержит восстановленную фактуру без старых описаний. Подписи — отдельные HTML-параграфы, обычный Arial, Flexbox; фон прозрачный, прямоугольных плашек нет.

home-reference-before-logo.png — присланный владельцем исходный макет.
home-approved-logo.png — тот же макет с утверждёнными DH и надписью вместо старого H.
home-approved-logo-proof.json и home-html-proof.json — попиксельная проверка сохранённых областей.

Узкий растровый шрифт владелец отклонил. Он не включён в текущий результат. Это локальный макет для визуальной приёмки, не новая рабочая главная страница и не замена демонстрационных данных. Разрешение на перенос всей композиции в приложение этим не предполагается.

Генеративный инструмент использован только для восстановления фона. Утверждённые логотипы размещены исходными PNG. Персонажи, рамки, волны и остальные области исходного макета сохранены пиксельно. Шрифты Windows не включены в Git; HTML использует системный Arial/Helvetica/sans-serif.
