# Макет главной страницы: актуальный просмотр

Открывать preview.html. Изображение home-restored-card-background.png содержит восстановленную фактуру без старых описаний. Подписи — отдельные HTML-параграфы, обычный Arial, Flexbox; фон прозрачный, прямоугольных плашек нет.

home-reference-before-logo.png — присланный владельцем исходный макет.
home-approved-logo.png — тот же макет с утверждёнными DH и надписью вместо старого H.
home-approved-logo-proof.json и home-html-proof.json — попиксельная проверка сохранённых областей.

Узкий растровый шрифт владелец отклонил. Он не включён в текущий результат. 29.10.2026 владелец прямо запросил перенос этой композиции на главную вместо опубликованной упрощённой страницы. Рабочая адаптивная реализация: components/shared/BrandPreview.tsx; источник: public/branding/home-approved/artwork.webp. preview.html сохранён как исходный полноразмерный образец. Генеративный инструмент использован только для восстановления фона. Утверждённые логотипы размещены исходными PNG. Персонажи, рамки, волны и остальные области исходного макета сохранены пиксельно. Шрифты Windows не включены в Git; HTML использует системный Arial/Helvetica/sans-serif.
