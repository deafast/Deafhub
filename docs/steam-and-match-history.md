## Что уже было и что изменено

Steam OpenID, серверная проверка ответа, привязка SteamID и запись `steam_accounts` уже существовали. Повторная разработка входа не выполнялась. В callback заменён `upsert` на insert-only: конкурентный запрос другого пользователя больше не может перезаписать владельца SteamID. Конфликт той же пары идемпотентен, другой владелец/второй SteamID/ошибка чтения отклоняются. Сохраняются nonce, state, проверка подписи/return_to и привязка к текущей сессии.

`GET /api/steam-profile` требует серверный `getUser`, читает SteamID только из собственной записи через RLS, не принимает произвольный SteamID от клиента. Ответы private/no-store. Запрос к фиксированному официальному GetPlayerSummaries/v2 с таймаутом 5 секунд, без редиректов. Ключ `STEAM_WEB_API_KEY` нужен только серверу; не использовать префикс NEXT_PUBLIC. Ключи/исходные ошибки не выводятся и не записываются в ответы.

Показываются только публичные никнейм, аватар с HTTPS-доменов Steam, подтверждённый ID, ссылка и время проверки. Для закрытого профиля не возвращаются имя/аватар. Не импортируются реальные имена, страна, друзья, игровые рейтинги. Отсутствующий ключ, недоступность API и закрытый профиль различаются в интерфейсе RU/EN. Steam OpenID подтверждает ID, но не рейтинг или достоверность никнейма.

История профиля уже использовала реальные `hub_matches` и состояние движка. Теперь раздел истории показывает только завершённые матчи зарегистрированного состава, сортирует по доступной дате, содержит ссылку на турнир и не выдаёт начало турнира за время завершения матча. Неподтверждённые встречи остаются в разделе матчей/турнира. Неизвестный счёт/дата не выдумываются. Сезонный рейтинг не создавался.

## Реальное состояние доступа

- Supabase `hvxvwgnnmazpptuenidv`: read-only проверены RLS обеих Steam-таблиц, SELECT authenticated только собственной записи, отсутствие клиентских INSERT/UPDATE/DELETE, PK SteamID и UNIQUE user_id. Настройки и данные не изменены.
- Vercel deafhub: поиск по всем окружениям `STEAM` и `FACEIT` не нашёл переменных. Новый ключ не создавался, настройки production не изменялись.
- Поэтому настоящий GetPlayerSummaries и полный Steam-login/link E2E не подтверждены. Код без ключа возвращает `unconfigured`, а не вымышленные данные.
- Источник API hub ограничивает выдачу (500 матчей/турниров, 5000 snapshot-участий). Это история доступной выборки, не обещание полного архива. Пагинация и отдельные даты завершения остаются задачей.

## FACEIT — отложено

Официальные Data API и правила API keys проверены. Нужен действительный серверный ключ с разрешённым доступом; OAuth/link и доступ к нужным данным отдельно проверяются перед внедрением. Ключ в окружении не найден, поэтому ELO/level не показываются и mock-значения не подставляются. Возможность получить полную историю изменений рейтинга не подтверждена; обычная история матчей не равна истории рейтинга.

Автоматический Dota 2 MMR, CS2 Premier Rating и полная история внешних рейтингов остаются отложенными. Статистика DEAF|HUB с ними не смешивается.
