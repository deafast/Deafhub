## Не завершено

- [ ] Подключение собственного SMTP и установка фирменного Confirm sign up в hosted Supabase: не выполнены. Панель блокирует редактор без SMTP; общие настройки проекта без отдельного согласования не изменяются. Реальная доставка Gmail/Mail.ru/Outlook, режимы почтовых клиентов, одноразовая ссылка и истечение требуют отдельного E2E. Нет подтверждённого результата этих проверок.

- [ ] Вместимость FC на 100 игроков: лимит **64** остаётся в движке, API и SQL
  `hub_engine_commit`. Нужны согласованное обновление и проверка базы/нагрузки.
- [ ] Индивидуальная регистрация FC без команды: текущая схема заявок связана
  с `team_id`; отдельный серверный путь и миграция пока отсутствуют.
- [ ] Миграционная история и полная проверка CAS/конкурентных HTTP-запросов:
  на предыдущей проверке список был пуст, хотя объекты существовали; новая
  миграция бронзы применена отдельно. История первоначальной схемы всё ещё
  требует сверки: наличие таблиц не доказывает применение baseline-миграций.
- [ ] Полный путь вошедшего игрока/капитана/организатора, вход по почте/Steam,

- [ ] Готовность команды, все условия, check-in и автоматический допуск;

- [ ] Realtime и отдельное расписание матчей.
