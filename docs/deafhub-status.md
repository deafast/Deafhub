## Не завершено

Порядок работ пересмотрен 21 октября: сначала короткие приёмочные проверки существующих функций, затем проверки с внешними условиями, в конце длительная разработка. Это приоритет, не обещание срока. Вход, реальные данные и доступы проверяются перед началом; отсутствие условий не задерживает независимые задачи.

Быстрая очередь: фильтр → история → условия/награды/организатор → сверка миграций и конкуренции → FC. Для первых трёх нужен авторизованный Preview и подходящие реальные записи; без них пункты не отмечать выполненными. Миграционная история не исправляется задним числом без проверки схемы.

Следом: общий путь входа и Steam. Для публичного Steam отсутствует ключ, SMTP затрагивает общие настройки проекта; не включать их вслепую ради тестовой ветки. Проверки физических устройств и РФ/РБ выполняются только при наличии соответствующей среды. Длительные realtime/расписание и check-in/двусторонние результаты/судьи идут последними.
