# Профиль: бирюзовые акценты и свободный фон

Ветка: `preview/deafhub-setup`. Основание: владелец утвердил макет профиля и попросил применить более выразительное бирюзовое оформление.

## Изменения

- Отдельный CSS-модуль профиля: обсидиановая основа, акцент `#22D3EE`, тонкое статическое свечение активного раздела и аватара.
- Верхний фон без рамки на ПК; на ширине до 600 px тот же фон покрывает всю область профиля. Использовано прежнее нейтральное утверждённое изображение. Персонаж в согласованном макете был примером пользовательской обложки и не установлен.
- Социальные значки 20 px, интерактивная область минимум 44 px. Действие редактирования — карандаш с локализованной доступной подписью.
- Обзор содержит реальные ник и регион, а также ссылку на команду. Статистика, награды и служебные пояснения доступны в своей вкладке; сохранены все шесть разделов.
- Для непривязанного Steam иконка ведёт в `/profile/settings#steam-account`, где сохранён существующий `AuthPanel`. Сервер проверяет только запись текущего пользователя; ошибка чтения не изображается как отсутствие привязки.
- Глобальные акценты шапки ограничены страницей с `data-player-profile`. Новых зависимостей, анимационных циклов, облачных записей или изменений схемы нет.

## Проверка

- 82 целевых теста: переключение разделов RU/EN, отсутствие статистики на обзоре, состояния Steam/VK/FACEIT, приватность/ошибки сессии, награды, контакты и настройки собственного Steam.
- Исправлен существующий стенд `steam-profile-history.cjs`: добавлены пропущенные заглушки уже существовавших импортов `provider-window` и `next/image`. Проверки поведения не удалены.
- ESLint трёх изменённых TSX и `git diff --check`: успешно.
- Сборка Next.js и TypeScript: успешно.
- Проверка React: новых эффектов и подписок нет, данные не копируются в состояние, операции записи не добавлены, ключи списков стабильны; у иконки редактирования есть aria-label/title, у кнопок разделов — активное состояние и связь с областью содержимого.
- Визуальная проверка ПК/мобильного в Brave не выполнена: инвентарь инструментов этой сессии содержит только Chrome. Реальный скриншот и отсутствие переполнения не подтверждены; генеративный макет не является доказательством опубликованной верстки.

## Остаток

- Код проверен локальным пакетом `e1db298`. Первоначально Git CLI не имел учётных данных, а GitHub API возвращал 403. Владелец завершил установку ChatGPT Codex Connector; установка для `deafast` теперь обнаружена. Сохранённый пакет передаётся через GitHub API в `preview/deafhub-setup` с проверкой исходного SHA. Статус развёртывания проверяется отдельно по фактическому коммиту; Production не публикуется.

- Загрузка своего аватара/баннера, обрезка и сохранение между устройствами ещё не реализованы. Фиктивных кнопок загрузки не добавлено. Для завершения потребуется отдельная реализация хранения с проверкой владения; действующие ограничения облачных изменений сохраняются.
- После доступности Brave проверить 360/390/1280/1920 px, длинный ник, RU/EN, переходы в настройки и вкладку статистики. Визуальная приёмка владельца открыта.
