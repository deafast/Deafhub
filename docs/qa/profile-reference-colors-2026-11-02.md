# Уточнение цветов по эталону владельца

Владелец сообщил, что фактический цвет не соответствует согласованному макету. Проверены источник CSS и назначения доменов Vercel:

- `www.deafhub.cc` обслуживает Production `c1d2945`, развёртывание `dpl_Et28TUc9znHqeG6dCgAx7TfKqX8u`.
- Тестовый профиль на момент замечания — Preview `425ef11`, развёртывание `dpl_E25x3o2FWGLxVHGiGiCozU2w6pZ3`.
- В первой реализации действительно оставался прежний акцент `#22D3EE`.

По присланному эталону уточнены только CSS профиля и ограниченные страницей профиля стили шапки: акцент `#00F0FC`, основа `#050E18`, холодный приглушённый текст, голубая двухконтурная рамка аватара, более выраженная синяя подсветка активного языка. Активная вкладка сохраняет бирюзу при наведении; добавлен небольшой маркер на её линии. Логотип и изображения не перекрашивались.

Проверка: `git diff --check`, согласованность переменных цвета, сборка Next.js и TypeScript успешны. Первый запуск сборки остановился из-за повреждённого локального кэша Turbopack; после переноса генерируемой `.next` в отдельный временный каталог чистая сборка прошла. Функциональная логика и зависимости не менялись, прежние 82 теста этого пакета повторно не запускались.

Цвета проверены по исходникам и эталонному изображению. Визуальная проверка опубликованного профиля в Brave остаётся открытой: разрешённый правилами проекта браузер не подключён. Скриншот эталона не выдаётся за снимок сайта. Собственные аватар и баннер ещё не загружаются.

Публикация ограничена Preview. Для переноса на `www.deafhub.cc` требуется прямое разрешение владельца согласно `AGENTS.md`; замечание о цвете не использовалось как разрешение менять Production.
