# Самостоятельное оформление соревнований и кабинета — 01.11.2026

Запрос владельца: ориентироваться на плотность/структуру турнирного и профильного примеров Alex.Skywalker, но сделать самостоятельный аналог DEAFHUB. Изображения, код, тексты и числовые значения Dribbble не копировались.

- Турниры: переключение игры сохраняет существующую URL-логику, добавлена сводка выбранного каталога, компактная таблица настоящих событий и ссылки к действующим формам/правилам. Счётчики используют только видимые после фильтрации события, допущенные заявки и назначенные матчи из существующего HubData. Никаких новых записей/рейтингов/призовых фондов.
- Кабинет: своя карточка игрока, боковое меню с иконками и игровыми ссылками; на мобильном меню в 3 колонки. Сохранены обзор, статистика, история, команда, турниры и прежнее сообщение недоступности кошелька. Состояния Steam/Google/FACEIT и серверная проверка профиля не менялись.
- Главная/бренд/финансы/данные/облачные настройки не затронуты. Посторонние Header/TextSizeControl/shell-navigation оставлены вне коммита.

Проверено локально: 64 теста PASS (game-filter, connected-account-logos, competition-presentation); Next.js build/TypeScript PASS. В IAB 1440/390 переключены Dota 2, CS2, FC: URL обновляется, логотипы загружаются, переполнения нет. В локальной среде API отвечает 503 без настроенного сервиса; данные и вход не подменялись. Профиль с действующей сессией и опубликованный каталог необходимо проверить после публикации. Визуальное принятие владельцем открыто.
