# Следующая ролевая приёмка Preview — конкретный план

Статус: подготовлено, не выполнялось; требуется разрешение на новый временный QA-набор в общей Preview-базе. Ограничение предыдущего checkpoint сохраняется.

## Точный объём

- Пять новых временных QA-аккаунтов: организатор, судья, два капитана, свободный игрок. Реальные аккаунты/профили/Steam не редактировать.
- Только цифровые роли, без платёжных разрешений. Временные роли организатора/судьи только для QA-набора.
- Две CS2-команды, одно LFP-объявление, два приватных приглашения: отказ от одного, принятие другого.
- Один помеченный QA CS2-турнир на две команды, одно расписание/перенос/отмена, check-in и один протокол с возражением/решением судьи; одна цифровая награда, без денег.
- После этого один отдельный QA FC-турнир на двух индивидуальных участников; проверить жеребьёвку/матч/закрытые роли.
- Два авторизованных окна только для QA, RU/EN и мобильная ширина. Все результаты явно искусственные, не сыгранные реальные матчи.

## Границы и очистка

Сначала сохранить перечень конкретных созданных UUID и исходные количества сущностей, без секретов. Проверять идентичность Preview. Существующие турниры владельца не менять и не использовать как фикстуры. При ошибке среды прекратить запись, сохранить точную стадию и список созданных UUID.

Удалить только созданные QA-сущности/временные роли после проверки по сохранённым UUID; подтвердить отсутствие остатков и неизменность существовавших записей. Auth-аккаунты удалять только если это заранее одобрено как часть этого одноразового набора. Финансы, SMTP, конфигурацию production и Steam-привязки не менять.
