# DEAF|HUB — дополнение к реестру задач: Steam, FACEIT и игровая история

Дата: 19 октября 2026.
Репозиторий: `deafast/Deafhub`; ветка: `preview/deafhub-setup`.
Это отдельное дополнение, НЕ замена `docs/deafhub-status.md` или `docs/01-DEAFHUB-WORK-TASKS.md`.

## Добавить в «Запланировано» (первый релиз)

- [ ] Привязка подтверждённого SteamID к профилю DEAF|HUB и отображение разрешённых публичных сведений профиля Steam. Увязать с существующей незавершённой авторизацией Steam. Проверить защиту от привязки чужого аккаунта, повторной привязки, раскрытия закрытых данных. Steam OpenID не даёт автоматически MMR, Premier Rating или полную историю.
- [ ] История собственных матчей и турниров DEAF|HUB: реальные результаты из БД, доступные игроку, корректные дата и статус, ссылки на турниры; без вымышленных данных и без смешивания с внешним MMR.
- [ ] FACEIT: проверить официальный способ привязки, права API и возможность получить ELO/уровень. Если доступ разрешён, реализовать отображение только подтверждённых данных и времени синхронизации. Если нет — оставить интеграцию отложенной; не блокировать релиз.

## Оставить в «Отложено»

- [ ] Автоматическое получение Dota 2 MMR и полной истории его изменений.
- [ ] Автоматическое получение CS2 Premier Rating/ранга и полной истории изменений.
- [ ] Исторические данные FACEIT, недоступные через разрешённый API, и любая внешняя статистика, требующая неподтверждённых источников.

## Ограничения

- Работать только в `preview/deafhub-setup`; не изменять `main` и production.
- Не обходить правила Steam/FACEIT, не собирать закрытые данные, не выдумывать рейтинги.
- Перед пометкой «Выполнено» проверить права, API, UI RU/EN, обработку отсутствующих данных, тесты и сборку.
- После внесения пунктов в `docs/deafhub-status.md` пересчитать категории без двойного учёта; этот документ сам по себе не подтверждает выполнение.
