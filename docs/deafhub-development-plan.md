# DeafHub — единый план разработки для ChatGPT Work

Дата: 19 октября 2026 года. Источник: план владельца, переданный полностью в чате.
Ниже сохранены его требования и порядок работ; это план, а не свидетельство выполнения.
Репозиторий: `deafast/Deafhub`. Рабочая ветка: `preview/deafhub-setup`.
Production: `www.deafhub.cc` — не изменять без явного разрешения владельца.

## 1. Цель и ограничения

Надёжная международная киберспортивная платформа для глухих и слабослышащих игроков.
Сохранять дизайн, цвета, анимации, образцы компонентов и 3D flip-карточки Claude.
Не выполнять улучшения дизайна без отдельного запроса. Не менять main или production.

## 2. Утверждённая турнирная концепция

- Dota 2: команды 5×5; ориентир 8–12 команд.
- CS2: команды 5×5; ориентир 32 команды.
- EA Sports FC: индивидуальные игроки 1×1; ориентир 100 игроков.
- Путь: регистрация → состав/подтверждения/допуск → группы → таблицы и тай-брейки
  → квалификация → Single/Double Elimination → финал → места → награды.
- Регламент задаёт BO1/BO3/BO5, BYE, Forfeit, тай-брейки, бронзу и гранд-финал.
- Результаты и сетки — только по подтверждённым данным; права и история действий
  проверяются сервером.
- Dota 2: командные места 1–3; два индивидуальных MVP всего турнира:
  CORE (позиции 1–3), SUPPORT (позиции 4–5).
- AI MVP Story: отдельная фактическая история игрока RU/EN по проверенной статистике,
  без вымышленных достижений; сохранять оборот существующих flip-карточек.
- CS2: места 1–3 командам, награда каждому зарегистрированному участнику;
  дополнительные MVP не согласованы. FC: индивидуальные места 1–3.
- Карточка награды: название сверху → крупный аватар/фото → никнейм → команда.
  Только зарегистрированный профиль; сохранять исторический снимок.
- Международная аудитория, визуальные статусы и текстовая коммуникация
  без обязательного голосового чата.

## 4. Первоочередные проверки

1. Свежие коммиты, рабочее дерево, завершение параллельной работы.
2. FC: голы не являются победами в BO-серии; реальные футбольные результаты,
   разрешение ничьих в плей-офф.
3. Лимит 64: обеспечить/подтвердить FC на 100 участников без перегрузки групп/сетки.
4. Single/Double для 8, 12, 32, 100: BYE, нижняя сетка, финал/сброс, места 1–3;
   отдельная бронза только по принятому регламенту.
5. Исправления: не терять зависимые сыгранные матчи без подтверждения и аудита;
   действующие награды должны блокировать исправление до предусмотренного отзыва.
6. Миграции Supabase, RLS, организатор, идемпотентность, конфликт версий,
   возврат тестовых данных.
7. Полный авторизованный путь игрока/капитана/организатора в Preview;
   доступность России/Беларуси проверять отдельно без обещания результата.
8. WebGL Canvas, Lenis, заставка: сначала измерения, не удалять вслепую.
   Сохранить дизайнерские образцы.

## 5. Единый реестр

В `docs/deafhub-status.md` четыре секции: «Выполнено (проверено)», «Не завершено»,
«Запланировано», «Отложено». Не дублировать задачи; готовность подтверждать проверкой.

Требуют подтверждения: почта/Steam/сессии; готовность команды/check-in;
двухсторонние результаты, доказательства, протесты, судьи; Realtime и расписание;
полный путь Preview, мобильный QA, доступность РФ; отдельная бронза по регламенту.

Владелец отложил Telegram/VK, расширенные визуальные уведомления/субтитры/жестовый язык,
внешнюю статистику, MVP CORE/SUPPORT, AI MVP Story. Финансы (платежи, кошельки,
взносы, комиссии, вывод, налоги) не разрабатывать без отдельного указания.

## 6. Утверждённая доработка существующих разделов

- Из `main:app/tournaments/TournamentHub.tsx` брать только ориентир переключения
  Dota 2 / CS2 / EA Sports FC (`dota`, `cs2`, `fc25` в старом макете).
  Не переносить overview как источник результатов.
- В Preview сохранять `HubPanel section="tournaments"` и серверные данные.
- В main `TeamLFPHub` содержит демонстрационные SOLARIS ESPORTS, CYBER WOLVES
  и рейтинги: на рабочие страницы их не переносить.
- В Preview сохранять `HubPanel section="teams"` и `TeamsDirectory` с настоящими данными.
- Не удалять/не редактировать игровые overview, TeamLFPHub, 3D flip-карточки:
  это визуальные образцы Claude.
- Турниры: три игры на одной странице; фильтр реально меняет видимые записи.
- Команды: настоящие составы, приглашения, места, поиск, фильтры.
  FC — индивидуальный 1v1, без искусственной команды из пяти человек.
- Таблица турнира: группы/результаты/очки/тай-брейки/плей-офф только из подтверждённого
  состояния движка. Общий сезонный рейтинг — отдельная сущность, только после
  согласования формулы и наличия проверенной статистики; иначе честное пустое состояние.
- Не плодить параллельные страницы. Не копировать main поверх Preview, старые
  TournamentHub/TeamLFPHub целиком, demo-overview или вымышленные лидерборды.
- Не добавлять выдуманные рейтинги/матчи/лица/обещания выплат.
- Для фильтра проверить URL/состояние, мобильный экран, RU/EN, клавиатуру,
  загрузку и пустые состояния. Не смешивать сезонный рейтинг с групповой таблицей.
- После внедрения: тесты, Preview, обновление реестра по доказанным результатам.
