# Расписание и обновление турнирного движка — 22 октября 2026

## Внедрено

Организатор назначает/меняет/отменяет время будущего матча в «Все матчи и результаты». Время хранится как canonical ISO UTC в matches[].scheduledAt; интерфейс показывает UTC. Нужна причина. Для сыгранных, BYE/пропущенных матчей и завершённого турнира изменение запрещено. Чужой организатор не сохраняет состояние. Сохранение использует прежний hub_engine_commit с CAS/идемпотентностью/аудитом, без отдельного обходного RPC.

Реальные результаты/составы не создаются автоматически. Опубликованное расписание сохраняется при внесении результата. Время ещё не доказывает фактическое начало/окончание игры. Предыдущий способ назначения ручных матчей сохранён.

TournamentEngine подписывается на INSERT/UPDATE только своего hub_engines через Supabase Realtime. Событие служит сигналом: актуальное состояние заново читается через защищённый HTTP API. Более старая ревизия не затирает новую. Запросы отменяются при уходе; соединение/таймеры/подписки очищаются. Бурст событий объединяется за 200мс. Ошибка сокета включает проверку раз в 30сек; скрытые страницы не опрашиваются, возврат на страницу запрашивает состояние. Это обновление движка, не обещание realtime для всех разделов сайта.

Миграция 20261022053120_tournament_realtime применена: публикация содержит hub_engines. Read-only проверка: RLS=true, anon SELECT=false, authenticated SELECT=true. RLS/GRANT/Auth/SMTP не менялись. Официальный механизм: https://supabase.com/docs/guides/realtime/postgres-changes .
