# FC: вместимость 100 участников — проверенный патч, внедрение ожидает подтверждения

19 октября 2026. База: Preview `2988c84`. Это предложение, не активная функция сайта.

Патч: [fc-capacity-100.patch](fc-capacity-100.patch). Применение `git apply --check` прошло на указанной базе. В нём:
- движок FC до 100, Dota/CS2 по-прежнему до 64; 101 FC / 65 команд отклоняются;
- согласованные пределы JSON API; лимит тела запроса сохранён;
- варианты 16/20/25 групп в существующей форме, для FC свыше 64 по умолчанию 20 групп;
- для FC свыше 64 круговые группы не крупнее 16 участников;
- миграция `20261019130440_fc_capacity_100.sql`, созданная официальной CLI 2.121.0: точечная замена единственного ограничения в текущем `hub_engine_commit`, без замены остального тела, ACL, RLS, аудита, CAS, проверок правил и наград. Неожиданное тело функции останавливает миграцию;
- воспроизводимый генератор транзакционного SQL-теста `scripts/fc-capacity-sql-check.mjs`. Записи имеют тестовые имена и должны откатываться. Он проверяет SQL-предел, повтор запроса, конфликт версии и права вызова; полноценность сетки проверяют отдельные тесты движка. В тесте использована старая командная схема как техническая фикстура, это не реализация индивидуальной регистрации FC.

Локально: 127 автоматических проверок (121 текущего сайта со значками + 6 новых FC), TypeScript, ESLint затронутых TS/TSX и Next webpack build прошли. Новые проверки: 100 участников Single/Double с обоими направлениями победы, BYE, reset, число поражений, 20 групп по 5 → 40 квалифицировавшихся → Double без повторной встречи своей группы в первом раунде, завершение турнира, размер состояния ниже текущего лимита SQL 2 МБ, отклонение переполнения и слишком крупных групп. Это не браузерная проверка 100 пользователей и не нагрузочный SLA.

Удалённо read-only сверено реальное тело RPC: предел 64 подтверждён. Попытка предварительного SQL-теста с временной заменой функции и тестовыми записями внутри rollback отклонена автоматической проверкой безопасности: общая Preview-база требует отдельного подтверждения. Тест НЕ выполнен, миграция НЕ применена, рабочий лимит остаётся 64. Обхода отклонения не выполнялось.

Для завершения требуется согласовать изменение только Preview Supabase `hvxvwgnnmazpptuenidv`: сначала транзакционная проверка с полным rollback, затем миграция и повторная проверка прав/ограничений/отката фикстур. После успешных SQL-проверок применить патч к исходникам Preview, проверить сборку и деплой. Production и main не затрагиваются. Индивидуальная регистрация FC без команды остаётся отдельным незавершённым пунктом.
