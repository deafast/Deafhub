## Отдельный бронзовый матч — внедрён в Preview

Полный патч: [single-bronze.patch](single-bronze.patch).
Миграция: `supabase/migrations/20261019042909_bronze_match_awards.sql`.

- Single Elimination, минимум четыре участника плей-офф.
- Только явно опубликованное правило `bronze_match` и включённый `bronzeMatch`.
- Участники BR1 — реальные проигравшие полуфиналов; чемпион — победитель финала.
- Завершение турнира/выдача наград ждут финал и бронзу, независимо от порядка игр.
- Для FC разрешены голы и отдельный решающий счёт пенальти.
- Награды: 1 — финал, 2 — проигравший финала, 3 — победитель BR1.
- Старые правила none/shared_semifinal/lower_final сохраняются.
- Исправления зависимых результатов требуют явного сброса; действующие награды
  блокируют изменения до отзыва.
- Права и RLS не расширяются. Новых пользователей/турниров миграция не создаёт.
- Проверка хешей базовых SQL-функций запрещает перезапись параллельных изменений.

Миграция применена 19 октября после отдельного разрешения владельца. Удалённая регрессия Supabase прошла: места 1–3, ожидание бронзы, повторная выдача и защита исправлений; тестовые записи откатились. Runtime опубликован в тестовую ветку. Демонстрация с восемью вымышленными командами: `/tournaments/demo`, только Preview, без сохранения в базе.

## Что проверено

- 73 автоматических теста, включая 54 движка: бронза для 4/5/8/12/32 участников,
  порядок финала/бронзы, группы → квалификация, FC-пенальти, явный сброс результатов,
  запрет Double и неполного состава плей-офф. Прежние тесты сохранены.
- TypeScript, ESLint изменённых компонентов и Next build --webpack прошли.
- Изолированный PostgreSQL PGlite 0.5.10: базовая схема, миграция, вся прежняя
  проверка наград и новый SQL-сценарий бронзы прошли. Проверены итоговые места,
  ожидание бронзы, несогласованное правило, повторная выдача, защита исправлений,
  откат фикстур. Удалённая Supabase этим локальным тестом не затрагивается.
- Локальная проверка не объявляется удалённой интеграцией или браузерным E2E.

В отдельной чистой рабочей копии Preview применить патч для воспроизведения:

```sh
git apply docs/proposals/single-bronze.patch
npm install --no-save --package-lock=false @electric-sql/pglite@0.5.10
node scripts/bronze-db-local.mjs
node --test lib/tournament/engine.test.mjs lib/tournament/result-form.test.mjs lib/tournament-filters.test.mjs maintenance/tests/team-directory.cjs maintenance/tests/game-filter.cjs
npx tsc --noEmit
npm run build -- --webpack
```

Патч не применяет миграцию к Supabase автоматически. Локальный SQL-runner
создаёт in-memory базу с минимальной auth-схемой; он не проверяет Supabase Auth.
