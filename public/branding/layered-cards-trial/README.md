# Пробная слоёная композиция

Только отдельный эксперимент; действующая главная не заменена. SVG-рамки — новые настоящие векторные формы, не трассировка. Персонажи PNG получены встроенным imagegen из all-cards.png, некоторые детали изменены генерацией; точное сохранение исходных RGB не заявляется. Исходный результат character-sheet.png сохранён. Из него выделены три PNG с прозрачностью. Логотипы — существующие оригинальные мобильные эмблемы из ../game-logos, без номера сезона. Подписи — HTML/CSS, без skew/rotate и отдельных плашек. Для возврата к утверждённому варианту достаточно закрыть пробную страницу.
