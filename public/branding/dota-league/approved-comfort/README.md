## Промпт для продолжения

Используй приложенный season-01.png как неизменяемую утверждённую основу DEAFHUB Cup. Подготовь сезон {N}. Замени только цифру в надписи DOTA 2 · SEASON 1 на {N}, сохранив положение строки, высоту букв, межбуквенные интервалы, цвет и резкость. Не генерируй заново весь баннер. Не меняй ни одного элемента вне области цифры: фон, диагонали, DEAFHUB, CUP и композиция должны остаться исходными. Никаких новых логотипов, персонажей, свечения, рамок или эффектов. Если точечная замена не сохраняет исходные пиксели, не выдавай её за точную; требуется отдельный редактируемый текстовый слой и проверка сравнения.

## Ограничения исходника

PNG создан imagegen, без слоёв. Сохранённый промпт сам по себе не гарантирует одинаковую повторную генерацию. Для неизменного оформления использовать этот PNG, а не повторную генерацию по описанию. Редактируемый мастер со сменным номером пока не подготовлен; будущие сезоны не объявлять готовыми до проверки. Этот растровый баннер не заменяет оригинальные файлы бренда и не является точным векторным логотипом.
