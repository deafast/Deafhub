# Начальная обложка профиля

`navy-landscape.webp` — оригинальная нейтральная иллюстрация для профиля, созданная 02.11.2026 встроенным imagegen после замечания владельца о несоответствии живой страницы согласованному макету. Сцена не использует персонажей, логотипов или игровых материалов.

Исходная панорама 2172×724 экспортирована в WebP quality=88 без изменения композиции; 61 642 байта. Слева оставлена спокойная область для аватара и ника, справа — архитектура и синие детали. CSS плавно скрывает нижний край, отдельной рамки вокруг обложки нет. На мобильном используется тот же фон по всей области профиля.

Это начальная нейтральная обложка. Загрузка пользовательского баннера и аватара ещё не реализована; не изображать иконки загрузки как работающие действия до подключения хранения.
