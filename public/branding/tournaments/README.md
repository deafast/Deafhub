# Источник турнирного фона Dota 2

Используется оригинальный файл Valve, без генерации, перерисовки, ретуши или увеличения:
https://cdn.steamstatic.com/apps/dota2/images/dota_react//home/heroes_full.jpg

Источник подключения: https://www.dota2.com/home и официальный CSS https://www.dota2.com/public/css/dota_react/main.css
Скачан 01.11.2026. Исходное разрешение 4000×2035 JPEG. Права на арт Dota 2 принадлежат Valve; файл не объявляется собственным или свободно лицензированным.
Композиция баннера адаптируется CSS background-size/position; надписи, утверждённый DEAFHUB, сезон и дата сохранены отдельными элементами.
Прежние сгенерированные исходники оставлены как история, в активном баннере не используются.
